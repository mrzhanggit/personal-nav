    • 1变量：给数据一个家

    想象你在打 RPG，背包里有一瓶血药、300 金币。程序也需要地方存放这些数据——这就是变量。

    你可以把变量理解为：一个贴了名字标签的魔法盒子。往盒子里放东西叫「赋值」，看盒子里有什么叫「读取」。

    hero_name
    "阿呆"
    文字 · str
    gold
    300
    整数 · int
    hp
    99.5
    小数 · float
    is_alive
    True
    真假 · bool

    把鼠标移到上面的盒子上看看。在 Python 里，创建一个变量只需要一行：

    hero_name = "阿呆" # 把文字 "阿呆" 装进名叫 hero_name 的盒子 gold = 300 # 把整数 300 装进名叫 gold 的盒子

    注意 = 不是数学的"等于"，而是赋值动作：把右边的东西，放进左边的盒子。盒子里的东西随时可以换：

    gold = 300 # 开局 300 金 gold = gold + 100 # 打怪赚了 100：先算右边 300+100=400，再放回盒子

    🧠 记忆口诀：先算右边，再放左边。

    2print()：让程序开口说话

    盒子里的东西藏在地牢里，怎么让玩家看见？用 print()——它会把括号里的内容「说」到屏幕上。

    hero_name = "阿呆" gold = 300 print(hero_name) # 说出盒子里的东西 print("金币：", gold) # 文字和数据可以一起说，逗号隔开
    阿呆 金币： 300

    三个新手必踩的坑：

    ① 引号很关键：print("gold") 输出的是字母 gold，而 print(gold) 输出的是盒子里的 300。带引号是"念台词"，不带引号是"看盒子"。

    ② 引号要成对：中文引号 "阿呆" 和英文引号 "阿呆" 长得像但不是一回事，Python 只认英文的 ' ' 或 " "。

    ③ print 要小写：写成 Print 会直接报错——Python 大小写敏感。

    3四大种族：数据类型

    魔法盒子里的东西分四大种族，种族不同、脾气不同：

    level = 10 # int · 整数 —— 能加减乘除 hp = 99.5 # float · 小数 —— 带小数点 name = "阿呆" # str · 字符串 —— 一串文字，必须带引号 is_alive = True # bool · 布尔 —— 只有 True / False 两种，注意首字母大写

    想查看任意盒子的种族？用 type()：

    print(type(99.5))
    <class 'float'>

    ⚠️ 最经典的坑：数字和文字不能直接相加。

    print("等级：" + 10) # 💥 报错！文字+整数，种族不通婚 print("等级：" + str(10)) # ✅ 先用 str() 把 10 变成文字 "10"

    万物皆可转：str() 转文字、int() 转整数、float() 转小数。这个技能下一课接 input 时会天天用。
