01

黎明 · 日本人的起源民族の黎明

约3.5万年前 — 公元3世纪

今天的日本人并非单一族群的后代。考古与基因证据表明，先后两批现代智人渡海而来，之后又有弥生人跨海迁入。 所谓「民族」，更多时候是一种文化认同，而非纯粹的血缘概念。

约3.5万年前

第一批现代智人抵达日本

+
背景

彼时处于冰河期，海平面较低，日本诸岛与亚洲大陆相连。这批智人从东北亚地区、靠近中国黑龙江入海口的库页岛一路走到日本，成为列岛最早的主人。

原因

人类自非洲走出后的持续迁徙与扩散；东亚大陆人口沿陆桥东移，追逐更宜居的环境。

影响

开始使用打制石器，留下今天考古学家所称的「小刀型石器」遗迹，确立了日本最早的人类文化层。

约2万年前

第二批移民与细石刀片文化

+
背景

又一批人群自西伯利亚出发，经朝鲜半岛渡海抵达日本东部地区，或与当地居民融合，或主导了当地社会。

原因

他们掌握了更先进的石器技术——细石刀片，在工具效率上形成代差优势。

影响

日本东部进入细石刀片文化时期；两种石器文化并存数千年后，更先进的细石刀片逐渐扩散到西日本，两批智人共同构成今天日本人最早的祖先。

约1万年前

绳纹时代：隔绝与融合

+
背景

最近一次大冰川覆盖时期结束，全球变暖、海平面上升，日本逐渐与亚洲大陆隔绝，进入绳纹时代。

原因

绳纹人身材较矮小、肤色较黑，与今天的日本人差异较大——基因上反而与青藏高原人群、台湾南岛民族有一定相似性。

影响

说明「绳纹人」更多是一个文化概念而非血缘概念：不同族群在民族形成过程中早已发生血缘融合，一个现代民族的祖先往往并不来自单一族群。

约前1000年 — 前5世纪

弥生时代：水稻、铁器与渡海者

+
背景

此时东亚文明已足够发达，能造出横跨朝鲜海峡与对马海峡的船只。一批被称为「弥生人」的人群自朝鲜半岛或长江三角洲地区渡海而来——时值中国春秋战国，或为逃避战乱。

原因

水稻自古代中国传入，至公元前5世纪已从九州北部普及到整个九州、四国与本州；同时弥生时代出现了铁器——日本几乎直接从石器时代「跳跃」进入铁器时代，未经历青铜时代。

影响

日本最早的农业社会由此开始，约公元前1000年即已出现；但此时尚无文字、无复杂社会结构、无城市，部落仍以母系血缘为纽带，居住在竖穴式房屋中，尚不能算文明的开始。

关于「徐福东渡」的传说：弥生时代结束于公元前3世纪，正值传说中徐福生活的秦朝。当时大批中国农民渡海而来，与徐福传说嫁接，成为今天一些日本人「文化认同」的符号——这与其说是认祖，不如说是认同东亚共同文化。——《谁是韩国人和日本人的祖先？》
公元3世纪

古坟时代：日本进入文明社会

+
背景

弥生时代之后，日本出现贵族营建的大型古坟，时代由此得名。

原因

人口增长与农业发展推动社会分层，阶级分化日益明显。

影响

通过考古可以断定，日本当时已进入复杂的阶级社会——这是日本正式进入文明社会的时间点，为随后大和政权的崛起与飞鸟时代的改革奠定基础。

02

飞鸟 · 大化改新大化の改新

645年 — 710年

飞鸟时代得名于奈良附近的飞鸟地方（飞鸟京 / 藤原京，今奈良县明日香村）。这一时代最大的事件，就是大化改新—— 它终结了豪族垄断政权的旧格局，把日本带上仿唐的中央集权之路。

645年6月

乙巳之变：刺杀苏我入鹿

+
背景

大化改新之前，日本朝廷里权臣苏我氏垄断政权，天皇家族反而没有太多实权。苏我入鹿是当时实际掌政的权臣。

原因

中大兄皇子联合另一派贵族发动政变，决意夺回皇室的权力。

影响

苏我入鹿被刺杀，皇室重掌大权；随后中大兄皇子等人拥立孝德天皇继位，大化改新由此拉开序幕。

646年 —

大化改新：仿唐的中央集权改革

+
背景

唐朝强盛的中央集权制度成为日本的改革蓝本；孝德天皇是大化改新的主导者。

原因

要建立强有力的中央政权，就必须打破豪族对土地与百姓的私人占有。

影响

土地制度上，废除豪族对土地和百姓的私有，将「私地私民」改为「公地公民」：土地不可继承、死后归还国家；国家对受田农民征收谷物，农民还需服劳役与兵役。「如果说中国的帝制始于秦始皇，那么日本的帝制则始于大化改新。」不过，这次改革并未彻底根除地方豪强与世家贵族的影响，为日后庄园制与武士崛起埋下伏笔。

03

奈良 · 律令国家奈良時代

710年 — 794年

迁都平城京（奈良）后，日本加强中央集权、建立户籍制度、推行租庸调。这一时期中日关系极好—— 遣唐使的友谊故事与鉴真东渡都发生在这个时代；但律令体制的裂痕也在同期显现。

710年 —

户籍、租庸调与土地国有的极限

+
背景

奈良时代，农民被固定在土地上，国家对农民课以租庸调或其他徭役，土地国有制度全面运转。

原因

到了奈良时代后期，以土地国有为基础的土地制度难以为继，寺院和地方豪族开始占有越来越多土地。

影响

日本逐渐进入庄园制时代。吴军提醒：不同的国家在同一个经济发展阶段，遇到的问题和出现的社会现象具有相似性——从某种意义上讲，这个时期的日本相当于罗马和中国古典文明时期。

754年

鉴真东渡：六次渡海终成功

+
背景

奈良时代中日关系非常好，遣唐使往来频繁；大海是当时难以逾越的天险，唐朝僧人鉴真为东渡日本努力了十年。

原因

前五次或因朝廷干预、或因船只沉没与漂流失败，直到第六次东渡（754年）才终于成功。

影响

鉴真带去的不只是佛法，还有唐朝的医学——今天日本的「汉方医学」正是以鉴真带去的唐朝医学为基础的。

奈良后期

近亲婚姻与皇嗣断绝

+
背景

当时的天皇为维持自身神圣性，通常采用近亲结婚。

原因

近亲婚配导致在任天皇的直系皇子大多病弱，相继早夭，最终天皇的直系子嗣断绝。

影响

奈良时代后期各种政治斗争频发，皇位继承危机成为平安时代权力格局变化的导火索之一。

04

平安 · 贵族与武士平安時代

794年 — 1185年

794年桓武天皇迁都平安京（京都）。京都按中国洛阳的格局和建筑风格修建，「洛」一度成为首都的代名词。律令制在此走向瓦解， 天皇虚位化，摄关政治登场——而一个新的阶层「武士」在时代转折中诞生。

794年

迁都平安京：「洛」与「上洛」

+
背景

桓武天皇将都城从奈良迁往平安京（京都）。

原因

京都按照中国洛阳的格局和建筑风格修建，当时日本常用「洛」字代表首都。

影响

后来日本地方贵族到京都觐见天皇，被称为「上洛」；直到今天，京都附近仍保留「洛东」「洛西」「洛南」「洛北」「洛中」等地名。

平安中期

律令制瓦解与武士阶层诞生

+
背景

平安时代，日本的律令制已难以为继：自耕农经济解体，税收征收不上来。

原因

朝廷指派地方豪族代表担任国司为政府筹税，地方权力增加、中央权力被削弱；同时自耕农越来越少，桓武天皇不得不废除以农民服兵役构成军队的军事制度，改为以志愿军组成军队。

影响

日本出现了一个全新的阶层——武士阶层。中央军事力量从此掌握在地方贵族手中，中央经济负担减轻但力量也被削弱。吴军对比指出：日本这一时期与古罗马后期颇为相似。

10—11世纪

摄关政治：藤原北家的世袭

+
背景

平安中期以后，中央官职开始被特定家族世袭。当继任天皇年幼时，往往由某个贵族担任辅佐天皇的摄政与关白（关白大致相当于中国的宰相）。

原因

10到11世纪，藤原北家开始世袭摄政与关白之位。

影响

此时的天皇已有点像后来的虚位君主，而藤原北家则有点像后来的幕府——贵族政治发展到极致，也为武家政治的登场铺平了道路。

平安后期

源平合战：武家时代的先声

+
背景

平安时代后期，军事贵族平氏与源氏两大世家开始争夺日本的实际权力，一开始平氏占上风。

原因

两大武士集团围绕中央政权与地方利益展开长期博弈。

影响

在源平合战中源氏获胜。最终源赖朝在镰仓建立幕府，并于1192年就任征夷大将军——日本自此进入幕府时代，武士正式登上政治舞台的中心。

05

幕府 · 武家天下幕府時代

1185年 — 1603年

从镰仓幕府到室町幕府，武家统治延续数百年。1467年应仁之乱后，日本进入战国时代—— 一个多世纪的封建主混战，把武士阶层推向了历史的聚光灯下。

1192年

镰仓幕府：征夷大将军的时代

+
背景

源平合战中源氏获胜，源赖朝掌握天下实权。

原因

源赖朝在镰仓建立幕府，于1192年就任征夷大将军。

影响

日本进入幕府时代——由将军与武士主导的武家政权取代了以天皇为核心的贵族朝廷，武士阶级成为日本政治的主角，此格局延续近七百年。

武士的兴起

从「家丁」到「雇佣兵」的武士

+
背景

日本最早的武士出现在645年大化改新之后。最初他们只是封建主的护从，类似中国看家护院的家丁，数量不多、未成阶层。

原因

后来天皇成为虚君、地方势力崛起，地方贵族为巩固权力纷纷雇佣武士作为私人武装——职业雇佣兵逐渐出现在日本社会中，形成了一个特殊的「劳动力市场」，只是从事的职业是打仗。

影响

与欧洲骑士不同：欧洲骑士自己也是贵族，而日本武士大多没有田地财产，只是受雇于领主，对领主依赖性更强。由于日本政治长期被武将左右，军人地位不低，一些武士凭战功成为将军和大名（封建主）。但早期武士粗鲁、残暴、缺乏教养，与后世文学形象相去甚远。

1467年

应仁之乱与战国时代

+
背景

室町幕府时期，两位掌握实权的大名发生武装冲突。

原因

幕府内部权力斗争激化，战火遍及日本全境。

影响

日本进入战国时代——此后一个多世纪封建主混战不休。战争让武士成为「香饽饽」，哪边给的好处多就投靠哪一方，武士地位不断提高。战国时期著名武士藤堂高虎一生投靠过多个家族、跟随过十几位主人——换主在当时是家常便饭。

06

江户 · 武士道的塑造武士道の形成

1603年 — 1868年

德川家康统一日本、建立德川幕府后，为政权的稳定开始「教化」武士——武士道其实从那时才真正出现。 它借助神道教、儒学与禅宗，把刀尖上的战士塑造成忠、义、勇、仁、礼、诚、克己的荣誉阶层。

1603年 —

德川幕府：以教化驯服武士

+
背景

战国混战之后，德川家康统一日本，建立德川幕府（江户时代）。

原因

为了政权与社会的稳定，幕府开始约束武士的行为，以免他们犯上作乱。这与中世纪欧洲教会约束骑士的做法相似——利用宗教作为工具来管教曾经无法无天的武士。

影响

武士道由此登场，成为日本文化中非常鲜明的标签。宗教工具包括日本自己的神道教（忠于主君、尊敬祖先）、从中国传去的佛教与儒家思想，以及禅宗的「专注、看淡生死、遇事平静沉着」。

江户时代

《叶隐闻书》：武士的《论语》

+
背景

江户时代对武士道的约束不仅是传统，还有配套著作作为武士学习的行为规范。武士道最初被称为「叶隐」，正来源于《叶隐闻书》。

原因

「叶隐」一词出自日本诗人西行之诗，意为如叶荫为领主提供庇护，要求武士在主人看不见的地方主动「舍身奉公」；书中更言「武士道者，死之谓也」——强调为忠义毫不犹豫地献身。

影响

书中为武士提出四条基本要求：行事绝不迟疑；对主公唯命是从（只服从直接上级）；孝敬长辈亲人；大慈大悲、不恃强凌弱方可为人。并规定了武士的基本美德——忠、义、勇、仁、礼、诚、克己。切腹仅是地位很高的武士才能采用的手段，对武士而言，很多惩罚比死还可怕。

江户后期

吉田松阴：武士道的新解读

+
背景

江户后期、明治维新之前，著名思想家吉田松阴出于「尊王攘夷、废除幕藩制」的目的，重新解读武士道。

原因

他把武士道强调的对领主的忠诚，解释为对天皇的效忠：「今之士名为武士，其本职在于平祸乱、夷贼。」而这件事只有奉天皇的命令才能做到。

影响

这种新解释造就了日本上下对天皇的忠诚；吉田松阴的国家观成为后来日本国家主义的重要组成部分。武士道中忠诚、勇敢、奉献的美德对日本国家的稳定乃至民族精神的塑造起到了积极作用——但也应警惕其中不符合当代价值观的糟粕部分。

07

开国 · 近代化之路明治維新

1868年 — 近代

德川幕府的倒台，最重要的原因是外来文化与制度的影响。明治维新之后，日本全面学习西方—— 接受西方文明，一度超越同时代的中国。这印证了吴军的判断：日本的超越来自「接受」，而非原生文明的自我演化。

幕末

德川幕府的倒台：外来冲击

+
背景

江户幕府长期锁国，维持着以武士阶层为核心的封建秩序。

原因

吴军在课程中明确指出：日本德川幕府的倒台，最重要的原因就是外来文化和制度的影响——这与基督教传入动摇罗马帝国、法国先进思想颠覆欧洲君主专制，是同一类历史模式。

影响

幕藩体制瓦解，尊王攘夷运动演变为倒幕运动，为明治维新铺平道路。

1868年 —

明治维新：全面学习西方

+
背景

明治政府建立后，日本以前所未有的速度吸收西方文明成果。

原因

在东亚地区自然条件最好的地方是中国的黄河流域与长江流域，周边国家很难发展出比中华文明更先进的文明形态——「到了近代，日本曾经一度超越中国，也是因为接受了西方文明，而不是它的原生文明实现了超越」。

影响

饮食结构上学习西方引入肉蛋奶，全民族身体发育程度与智力水平提高；经济上部分采用重商主义政策——18、19世纪的美国、19世纪的德国和日本在崛起时都采用了这一策略，重商主义几乎成为各国工业化初期的共同路径。启蒙思想家福泽谕吉等坚决反对封建制度，推动近代思想解放。

中日交往 · 渡海之桥一衣帯水

日本在中世纪基本是「接受中国文化，但对中国本身没有施加什么政治影响」——但渡海而来的交流从未中断：从遣唐使到瓷器，从宁波之乱到浮世绘。

SHITŌSHI

遣唐使与唐日贸易

奈良时代（710—794）

日本主要向唐朝输出白银、少量布料，从唐朝进口丝绸、香料、中药、经典书籍和佛像。安史之乱前，唐日贸易伴随遣唐使的朝贡顺带进行，属官方贸易——唐朝商人在鸿胪馆停留三到六个月，货物「官司先买」，之后才轮到贵族和寺院。

KAISEKI

文化东传：佛经与医学

唐代

玄奘翻译的七十余部佛经后来传到朝鲜、日本和越南；唐朝医学也传往日本与新罗，日本汉方医学以鉴真带去的唐朝医学为基础。9世纪起《论语》等儒家经典成为日本人学习的启蒙经典，孔庙至今在日本保留十余座。

GŌTOKU

宁波之乱与倭寇之患

明代

明朝实行海禁后，走私贸易反而兴盛。华人宋素卿在日本长大成为幕府家臣，其船队与另一日本船队争夺对明贸易发生纠纷，史称「宁波之乱」。此后对日官方贸易大门关闭，海盗首领雇佣日本浪人（倭寇）袭扰东南沿海，汪直是其中代表。

NAGASAKI

澳门—长崎航线与白银

16—17世纪

澳门成为连接欧洲、印度、日本、东南亚与中国贸易的枢纽，葡萄牙人开辟澳门到长崎的航线。大量白银流入让明朝成为银本位王朝，中晚明白银的货币化反过来又刺激了西班牙和日本开采更多白银。

JIKI

瓷器：打破中国的垄断

17世纪

在17世纪日本人掌握瓷器制作技术之前，朝鲜是中国以外唯一能自造瓷器的国家。荷兰东印度公司因多年无法从中国获得瓷器、库存告罄，转而向日本订购——中国对瓷器的垄断就此结束。

UKIYO-E

浮世绘：套色雕版之美

江户时代

中国的雕版印刷技术传至周边国家，今天日本在世界上很受欢迎的浮世绘，正是套色雕版印刷的产物——这是中日技术交流结出的艺术果实。

BUNMEI NO HIMITSU

文明密码日本の独自性

《吴军来信 · 世界文明史》对日本文明的四点核心判断。

「相似却不相同」的独特文明

  • 学习的文明。日本受到中华文明的极大影响，却在后来的发展中逐渐产生与中华文明相似、却不相同的独特文明——它没有被中华文明取代，反而极大丰富了世界文明。

  • 地理的孤岛。大海是当时难以逾越的天险（鉴真六次东渡才成功），日本与中原王朝各自独立发展——如同喜马拉雅山两侧的古中国与古印度。

  • 未完成的集权。大化改新学习唐朝中央集权，却没有像中原王朝那样再度走向统一；相反，地方豪强建立自己的武装，名义上拥戴共主、实际上各自为政，与天皇分享权力，天皇逐渐变为虚位君主——庄园制与封建贵族制延续到近代。

  • 超越来自接受。「到了近代，日本曾经一度超越中国，也是因为接受了西方文明，而不是它的原生文明实现了超越。」明治维新后引入肉蛋奶改善体质、采用重商主义崛起——接受外来文明，是日本实现跨越的根本方式。
