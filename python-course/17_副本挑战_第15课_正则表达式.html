    • 1re 三大武器：findall / search / match

    在一大段文字里找东西，字符串的 in 和 .find() 只能找"死字"。要找"所有手机号"、"所有日期"这种有规律的目标，就得用正则表达式——一串描述规律的暗号，交给 re 模块去执行。

    三大武器各司其职：

    import re text = "订单A102已发货" print(re.findall(r"\d+", text)) # 武器一：一网打尽，返回列表 m = re.search(r"\d+", text) # 武器二：只找第一处，返回 Match 对象 print(m.group()) # 用 .group() 取出匹配到的文字 print(re.match(r"\d+", text)) # 武器三：只从开头找 → 没找到，None
    ['102'] 102 None

    ① findall：找出所有匹配，装进列表还给你——用得最多。

    ② search：全文扫描，找到第一处就收手，结果要用 .group() 取出来；没找到返回 None。

    ③ match：只肯从字符串开头匹配。开头不对，后面再像也白搭：

    m = re.match(r"\d+", "102元已支付") # 开头就是数字，match 有戏 print(m.group()) # 102

    2元字符：一个符号，一类字符

    正则的精髓是"暗号"：一个反斜杠符号代表一整类字符。先认识四大天王——

    \d
    任意一个数字
    0-9，共 10 种
    \w
    字母/数字/下划线
    Python 里连中文都认
    \s
    任意一个空白
    空格、Tab、换行
    .
    任意一个字符
    几乎啥都行，唯独不匹配换行

    把鼠标移到暗号卡片上感受一下。实战验证：

    print(re.findall(r"\w+", "hi 你好 666")) # \w 连中文都认 print(re.findall(r"a.c", "abc a c a\nc")) # 点号不匹配换行符
    ['hi', '你好', '666'] ['abc', 'a c']

    想自定义"备选名单"？用字符组 [ ]：方括号里列出可选字符，只能选一个；中间加 - 表示范围。

    print(re.findall(r"[A-Za-z]+", "Hello World 123")) # 只抓英文单词 print(re.findall(r"[0-9]", "a1b2")) # 等价于 \d
    ['Hello', 'World'] ['1', '2']

    [abc] 表示 a 或 b 或 c；[a-z] 表示小写字母；[a-zA-Z0-9] 表示字母加数字。字符组是"点菜"，一次只上一个字符。

    3量词与锚点：几个？在哪？

    元字符一次只匹配一个字符。想匹配"一串"，得在后面挂量词：

    # + 一个及以上 * 零个及以上 ? 零个或一个 {m,n} m 到 n 个 print(re.findall(r"colou?r", "color colour colouur")) # u 可有可无 print(re.findall(r"\d{2,4}", "1 12 123 1234")) # 2~4 位数字
    ['color', 'colour'] ['12', '123', '1234']

    注意上面第二行：单独的 "1" 不够 2 位，被跳过了；"colouur" 有两个 u 也不符合 u?，所以没被选中。

    还有两个"钉子"——锚点：^ 钉在字符串开头，$ 钉在结尾。它们不匹配任何字符，只规定位置：

    print(re.search(r"^Py", "Python")) # 开头是 Py → 中！ print(re.search(r"^Py", "I love Python")) # Py 不在开头 → None，search 也救不了 ^
    <re.Match object; span=(0, 2), match='Py'> None

    4分组、贪婪与 r"" 三大心法

    分组 ( )：把正则里的一段圈起来，既能整体引用，也能单独提取。用 group(1) 取第 1 个括号里的内容，group(0) 是整个匹配：

    m = re.search(r"(\d{4})-(\d{2})-(\d{2})", "今天 2025-01-18 开会") print(m.group(0)) # 整个匹配：2025-01-18 print(m.group(1)) # 第 1 组：年 print(m.group(2)) # 第 2 组：月
    2025-01-18 2025 01

    ⚠️ 小心：findall 遇到分组会变脸——返回的不再是整个匹配，而是分组内容组成的元组：

    print(re.findall(r"(\d{4})-(\d{2})", "2025-01-18 和 2025-02-14"))
    [('2025', '01'), ('2025', '02')]

    贪婪 vs 非贪婪：量词默认贪心，能多吃绝不停嘴；加个 ? 变成"见好就收"。点下面按钮体会区别：

    <a><b><c>

    原始字符串 r""：正则里全是反斜杠，而普通字符串会先把 \b、\d 这类组合"翻译"掉。给正则穿上 r 外套，反斜杠才能原样送达 re 引擎：

    print(re.findall("\bcat\b", "the cat sat")) # 普通字符串：空手而归 print(re.findall(r"\bcat\b", "the cat sat")) # 原始字符串：抓到猫！
    [] ['cat']

    原来普通字符串里的 \b 早已被 Python 翻译成"退格"字符，正则引擎根本没见到 \b（单词边界）。写正则，永远加 r。

    5猎人的弹药库：三大经典套路

    把学过的招式串起来，就能猎捕真实世界的"情报"：

    phone = r"1[3-9]\d{9}" # 手机号：1 开头，第 2 位 3-9，再跟 9 位数字 email = r"[\w.]+@[\w.]+" # 邮箱（简化版）：字符@字符 date = r"\d{4}-\d{2}-\d{2}" # 日期：2025-01-18 这种 print(re.findall(phone, "电话13812345678，备用15987654321")) print(re.search(date, "截止 2025-01-20").group())
    ['13812345678', '15987654321'] 2025-01-20

    最后是打码神器 re.sub：把匹配到的内容批量替换。配合分组引用 \1 \2，只遮住中间 4 位：

    secret = re.sub(r"(\d{3})\d{4}(\d{4})", r"\1****\2", "13812345678") print(secret)
    138****5678

    (\d{3}) 和 (\d{4}) 抓住头尾，中间 4 位换成星号；替换文本里的 \1、\2 表示"把第 1、2 组原样放回"。

    ⚠️ 分组陷阱：金额模式里写的是非捕获分组 (?:\.\d+)?。如果写成普通分组 (\.\d+)?，findall 会只返回括号里的内容：['', '', '.9']（空字符串和 ".9"），而不是你想要的金额整体。规则：findall 遇到分组，返回分组内容；只想分组不想提取，就用 (?:...)。
