    • 1列表推导式：一行的炼金术

    新手想把每个数翻倍，要写三步：建空列表 → for 循环 → append。Python 高手一条咒文搞定：

    nums = [1, 2, 3, 4, 5] doubled = [x * 2 for x in nums] print(doubled)
    [2, 4, 6, 8, 10]

    它就是一条流水线：每个元素从 nums 里排队走出，被加工成 x * 2，再装进新列表：

    12345 ──×2──▶ 246810

    读法有诀窍：先读 for，再读前面的表达式——「对于 nums 里的每个 x，算出 x * 2，收集成列表」。等价的传统写法长这样，推导式只是把四行压成了一行：

    doubled = [] for x in nums: doubled.append(x * 2) # 与 [x * 2 for x in nums] 完全等价

    🧠 记忆口诀：中括号开头，for 前是加工、for 后是来源。

    2if 的两种位置：筛选 vs 变换（高频混淆点）

    if 出现在推导式的不同位置，含义完全不同——这是本课最容易翻车的地方，务必盯紧：

    if 在 for 后面 = 筛选（安检门）
    positives = [x for x in nums if x > 0]
    只有满足条件的元素能通过，其余被丢掉——数量可能变少
    if-else 在 for 前面 = 变换（化妆间）
    labels = ["正" if x > 0 else "负" for x in nums]
    每个元素都会保留，只是按条件改头换面——数量不变

    同一条 nums 上跑两种魔法，对比着看：

    nums = [3, -1, 4, -5, 2] positives = [x for x in nums if x > 0] # 筛选：留下正数 labels = ["正" if x > 0 else "负" for x in nums] # 变换：正负贴标签 print(positives) print(labels)
    [3, 4, 2] ['正', '负', '正', '负', '正']

    🧠 一秒判断口诀：后筛前换。if 跟在 for 后面做减法（筛选），if-else 站在 for 前面做替换（变换）。另外注意：筛选版只有 if 没有 else，变换版必须 if 和 else 成对出现。

    3嵌套推导 · 字典 / 集合推导式

    推导式可以写两层 for，把嵌套循环也压成一行。顺序规则：外层 for 在前，内层 for 在后，和嵌套循环的书写顺序一模一样：

    pairs = [[1, 2], [3, 4]] flat = [x for row in pairs for x in row] # 外层取 row，内层取 x print(flat) # 等价的传统嵌套写法： flat = [] for row in pairs: for x in row: flat.append(x)
    [1, 2, 3, 4]

    把中括号换成花括号，就得到字典推导式（键: 值）或集合推导式（自动去重）：

    names = ["hp", "mp"] values = [100, 60] stats = {k: v for k, v in zip(names, values)} # 字典推导式 print(stats) s = {x % 3 for x in range(10)} # 集合推导式：去重 print(s)
    {'hp': 100, 'mp': 60} {0, 1, 2}

    区分技巧：花括号里有冒号是字典，没冒号是集合。range(10) 里 10 个数除以 3 的余数只有 0、1、2 三种，集合自动把重复的合并掉了。

    4生成器：圆括号与 next()

    把推导式的中括号 [ ] 换成圆括号 ( )，得到的不是列表，而是生成器——一条按需供货的流水线。取货要用 next()：

    g = (x * x for x in range(3)) # 圆括号 = 生成器 print(next(g)) # 取第 1 个：0*0 print(next(g)) # 取第 2 个：1*1 print(next(g)) # 取第 3 个：2*2 print(next(g)) # 已经取完了 → 抛出 StopIteration！
    0 1 4 StopIteration

    生成器像扭蛋机：摇一次出一个，出了就不能塞回去。全部摇完后再摇，机器直接亮红灯（抛 StopIteration 异常）。

    5惰性求值：省内存的终极奥义

    列表推导式是「先全部装满背包再出发」；生成器是「路上现做现吃」——用到哪个才算哪个，这就是惰性求值：

    g = (x for x in range(10**8)) # 一亿个数：一个都还没算！ print("生成器已就绪！") # 立刻执行，毫无压力 print(next(g)) # 这一刻才算了第一个数
    生成器已就绪！ 0

    实测对比：装下一百万个数的列表约 8.45 MB，同款生成器只要 208 字节——因为它根本不存数，只存"配方"。

    [x for x in ...]列表：出发前全部装好 · 随便反复用
    (x for x in ...)生成器：按需现做 · 只能往前走
    range(10**8)天生的惰性对象，从不真造一亿个数

    你其实早就用过惰性对象——range() 就是官方自带的"生成器亲戚"：

    r = range(10**8) print(10**8 - 1 in r) # 秒答！range 不用真造一亿个数
    True

    生成器的另一个脾气：一次性（exhausted）——喝完就空，倒不出第二杯：

    g = (x for x in "abc") print(list(g)) # 第一次：全部倒出来 print(list(g)) # 第二次：杯子已空 → []
    ['a', 'b', 'c'] []

    🧠 选用口诀：要反复用、要下标，选列表；数据巨大、只走一遍，选生成器。
