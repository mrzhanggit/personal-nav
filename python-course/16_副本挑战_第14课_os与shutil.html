    • 1os 模块：程序的眼睛和手

    到目前为止，你的程序只能记住内存里的数据——关机就忘。想读写硬盘上的文件、浏览文件夹，就需要请出 Python 自带的os 模块。它是「operating system」的缩写，是程序与操作系统之间的翻译官。

    管家上岗第一件事：先弄清楚我在哪、周围有什么。

    📁 pyproject 当前目录
    📄 demo.py 文件
    📄 notes.txt 文件
    📁 data 文件夹
    📁 图片 文件夹

    把鼠标移到目录树的条目上看看。对应的代码只有两行：

    import os print(os.getcwd()) # 我现在在哪个目录？（get current working directory） print(sorted(os.listdir("."))) # 当前目录下有哪些条目？（sorted 让顺序稳定）
    /Users/adeai/pyproject ['data', 'demo.py', 'notes.txt', '图片']

    三个要点：

    ① os.getcwd() 返回当前工作目录的路径——你的程序此刻"站"在哪里。

    ② os.listdir(".") 返回一个列表，装着目录里所有条目的名字（文件和文件夹都有，但只看一层，不会钻进子文件夹）。不加 sorted 的话，顺序是不保证的。

    ③ "." 表示当前目录，".." 表示上一级目录。

    2os.path 四件套：探路神器

    动手搬文件之前，得先探路：这条路存不存在？是文件还是文件夹？这就轮到 os.path 家族出场。

    os.path.exists("notes.txt") # 这条路径存在吗？→ True / False os.path.isfile("notes.txt") # 是一个文件吗？ os.path.isdir("图片") # 是一个文件夹吗？（文件和文件夹互斥） os.path.join("data", "a.txt") # 把两段路径拼成一条

    🧪 亲自试试：下面是刚才那棵目录树，选一条路径，再点按钮查看结果。

    ⚠️ join 的跨平台陷阱：macOS 和 Linux 用 / 分隔路径，Windows 却用 \。同一个 join，两边结果不同：

    os.path.join("data", "a.txt") # 在 macOS / Linux 上 → 'data/a.txt' # 在 Windows 上 → 'data\a.txt'（反斜杠）

    所以拼路径永远用 join，永远别手写分隔符——你的程序才能在所有电脑上活着。

    还有个拆名字的好工具 os.path.splitext：把文件名拆成「主名 + 扩展名」。

    print(os.path.splitext("攻略.pdf")) print(os.path.splitext("a.tar.gz")) # 只认最后一个点！
    ('攻略', '.pdf') ('a.tar', '.gz')

    3建文件夹与遍历：os 的进阶操作

    想让程序自己建目录？os.makedirs 可以一次建出多级文件夹，而且有个保命参数：

    os.makedirs("下载/图片", exist_ok=True)

    ① 「下载」和「图片」两级会一起创建（父目录不存在也没关系）；② exist_ok=True 表示"已经存在也不报错"。不加这个参数，第二次运行就会炸出 FileExistsError——写脚本时加上它，脚本就能反复运行不出错。

    遍历文件夹的标准套路：for + listdir + isfile：

    for name in os.listdir("下载"): full = os.path.join("下载", name) # 拼出完整路径，专业习惯 if os.path.isfile(full): print("文件：", name) else: print("文件夹：", name)

    如果文件夹套文件夹、还想要连子文件夹一起钻进去，就用 os.walk（走遍整棵目录树）。它每次交给你三个值：root（现在走到哪）、dirs（这里的子文件夹列表）、files（这里的文件列表）。

    for root, dirs, files in os.walk("项目"): print(root, dirs, files)
    项目 ['utils', 'docs'] ['config.txt', 'main.py'] 项目/utils [] ['helper.py'] 项目/docs [] ['readme.md']

    （示例输出，子文件夹的顺序在不同电脑上可能不同）

    4shutil：搬家公司 + 一把砍树刀

    os 负责看路，shutil 负责干活：复制、移动、删除，它全包了。

    import shutil # 复制：原件原地不动，多出一份副本 shutil.copy("攻略.pdf", "备份/攻略.pdf") # 移动（搬家）：搬完之后，原位置就没了 shutil.move("旧作业.docx", "文档/旧作业.docx")

    一句话记住区别：copy 是复制，原件还在；move 是搬家，原件消失。

    ⚠️ rmtree 是本课最危险的技能，没有之一
    shutil.rmtree("测试数据") 会把「测试数据」整个文件夹连同里面所有子文件夹、所有文件全部删除——不进回收站，删了就是删了，无法撤销。路径写错一格，多年珍藏瞬间蒸发。rmtree = remove tree，连根拔树。

    所以本课立下一条安全铁律：删除之前，永远先 print 确认内容，再问一句"真的要删吗"：

    print(os.listdir("测试数据")) # 第一步：先看清里面装了什么 answer = input("确认删除？(y/n) ") # 第二步：再让人拍板 if answer == "y": shutil.rmtree("测试数据") # 第三步：看清了才准删
