    • 1列表：一整排储物柜

    前 5 课的变量一次只能装一个数据——但 RPG 背包里明明有血药、短剑、火把……总不能写 20 个变量？列表（list）就是一整排编了号的储物柜：

    backpack = ["血药", "短剑", "火把", "干粮"] # 方括号 + 逗号分隔
    [0]
    血药
    0 号柜
    [1]
    短剑
    1 号柜
    [2]
    火把
    2 号柜
    [3]
    干粮
    3 号柜

    ⚠️ 程序员数数从 0 开始：第一个物品是 [0]，不是 [1]！这是本课第一大坑。取物品用中括号 + 编号：

    backpack = ["血药", "短剑", "火把", "干粮"] print(backpack[0]) # 索引从 0 开始：取第 1 个 print(backpack[3]) # 4 个物品，最大索引是 3 print(backpack[-1]) # 负索引：从末尾往前数，-1 是最后一个 print(backpack[-2]) # 倒数第二个
    血药 干粮 干粮 火把

    索引超界会怎样？——BOSS 战教过你"防御性思维"，看好了：

    print(backpack[4]) # 只有 4 个物品，索引最大是 3，没有 4 号柜！
    IndexError: list index out of range

    记住公式：最大索引 = 元素个数 - 1。想要"最后一个"，用 [len(backpack) - 1] 或者干脆 [-1]。

    2背包四绝技：append / insert / remove / pop

    列表是可变的——柜子里的东西随时能换。四大绝技对应"放入、插入、按名扔、按位扔"：

    backpack = ["血药", "短剑", "火把"] backpack.append("月光石") # append：放到背包末尾 backpack.insert(1, "盾牌") # insert：插到 1 号位，后面的自动往后挪 print(backpack) backpack.remove("火把") # remove：按名字删除（只删找到的第一个） lost = backpack.pop() # pop()：弹出最后一个，并返回它 print(backpack) print("弹出的是：", lost)
    ['血药', '盾牌', '短剑', '火把', '月光石'] ['血药', '盾牌', '短剑'] 弹出的是： 月光石

    注意 pop() 最特别：删掉的同时把值还给你，所以能用变量接住。pop 还能带索引：backpack.pop(0) 表示弹出 0 号位。remove 找不到物品时会报 ValueError，删之前最好先判断一下。

    判断背包里有没有某件装备？用 in——它返回 True / False：

    backpack = ["血药", "短剑", "火把"] print("血药" in backpack) print("魔杖" in backpack) if "血药" in backpack: print("血药充足，可以放心进副本！")
    True False 血药充足，可以放心进副本！

    3鉴定术：统计四兄弟与切片

    拿到一排装备价格，统计需求一个函数搞定：

    prices = [10, 25, 5, 99, 30] print("共", len(prices), "件") # len：数个数 print("最贵", max(prices)) # max：最大值 print("最便宜", min(prices)) # min：最小值 print("总价", sum(prices)) # sum：求和
    共 5 件 最贵 99 最便宜 5 总价 169

    切片（slicing）是一次取出一段物品，格式 列表[开始:结束]，铁律是含头不含尾——取得到"开始"编号，取不到"结束"编号：

    backpack = ["血药", "短剑", "火把", "干粮", "金币袋"] print(backpack[1:3]) # 取 1、2 号（3 号不含） print(backpack[:2]) # 省略开头 = 从 0 开始 print(backpack[2:]) # 省略结尾 = 一直取到末尾
    ['短剑', '火把'] ['血药', '短剑'] ['火把', '干粮', '金币袋']

    记忆口诀：[1:3] 就是"1 号起，3 号止"——含头不含尾。切片切多了也不报错：[1:100] 会安静地取到最后。

    排序有两位法师，别搞混：

    prices = [30, 5, 99, 10] print(sorted(prices)) # sorted：变出一个新列表（从小到大），原列表不动 print(prices) # 果然还是原顺序 prices.sort() # sort：就地重排，直接改原列表，没有返回值 print(prices)
    [5, 10, 30, 99] [30, 5, 99, 10] [5, 10, 30, 99]

    经典陷阱：print(prices.sort()) 输出 None！因为 sort() 只负责重排、不返回任何东西。想"打印排序结果"用 sorted()，想"永久排序"用 sort()。另外 sort(reverse=True) 可以从大到小排。

    4元组：一次封印，终生不变

    有些数据天生不该被改动——比如角色的出生坐标、一年四季的名字。元组（tuple）就是不可变的列表：圆括号创建，一旦封印，谁也改不了：

    position = (3, 5) # 元组用圆括号 print(position[0]) # 索引、切片、len、in……查询操作和列表一样 x, y = position # 解包：一次把元组里的值分给多个变量 print("角色坐标：", x, y)
    3 角色坐标： 3 5

    但只要想改它，立刻翻脸：

    position = (3, 5) position[0] = 10 # 💥 元组不可变！没有 append、没有 remove、没有排序
    TypeError: 'tuple' object does not support item assignment

    什么时候用元组？数据定了就不该变的时候：坐标、RGB 颜色、(年, 月, 日)。它还比列表省内存、防手滑——想改都改不了，就不会出 bug。

    解包（unpacking）是个神技，左边变量个数要和右边对齐：

    hp, mp = 100, 50 # 右边其实是元组 (100, 50)，可省括号 hp, mp = mp, hp # 一行交换两个变量！右边先打包，再解包给左边 print(hp, mp)
    50 100

    冷知识：只有一个元素的元组必须带逗号 ("血药",)——只写 ("血药") 只是一个带括号的字符串。
