    2🗺️ 作战计划 · 大项目拆解术

    职业开发者的秘密：再大的项目也是拆成小块，一块一块写、一块一块测。我们的作战计划分 5 个阶段：

    ① 配置区用字典定义「分类 → 扩展名列表」规则，改规则只改一处
    ② 扫描os.listdir 列出文件夹内容，只挑出文件、跳过子文件夹
    ③ 分类规则os.path.splitext 拿扩展名，查字典定归属
    ④ 移动shutil.move 搬家，移动前 exists 检查防覆盖
    ⑤ 日志与统计追加模式写日志、字典计数、运行结束打印统计

    每个阶段写完都立刻运行一次，确认没问题再写下一块——这叫"小步快跑"。整理脚本最怕"顺手把重要文件搬丢了"，所以每一步我们都带安全检查。

    3🔨 分步搭建 · 跟着敲就对了

    先在电脑上建一个练习文件夹（比如 模拟桌面），往里面随便丢几个不同类型的文件（.jpg、.txt、.pdf……）。然后亲手逐行敲出下面的代码（不要复制粘贴！）。每一步都接在上一步后面，累计起来就是完整项目。

    STEP 1配置区 —— 规则写进字典，建房用 makedirs

    整理器的灵魂是分类规则。用什么存？「分类名 → 一堆扩展名」正好是字典的形状：键是分类名，值是扩展名列表。以后想加新分类，只改这一处。

    import os RULES = { "图片": [".jpg", ".png", ".gif"], "文档": [".pdf", ".txt", ".docx"], } for category in RULES: # 遍历字典的键：图片、文档 folder = os.path.join("./模拟桌面", category) # 拼出 ./模拟桌面/图片 if not os.path.exists(folder): # 不存在才建，存在的跳过 os.makedirs(folder) print("[建房]", category + "/")
    [建房] 图片/ [建房] 文档/

    两个要点：① os.path.join() 自动处理路径分隔符，比手写字符串拼接稳妥（Windows 和 Mac 的分隔符还不一样呢）；② 先 exists 再创建，第二次运行就不会对着已存在的文件夹报错——这也是后面 Quiz 的考点。

    STEP 2扫描文件夹 —— 只挑文件，别碰子文件夹

    os.listdir() 会列出文件夹里的一切——文件和子文件夹混在一起。我们只要散落的文件（子文件夹是刚建的"房间"，当然不能整理它自己），用 os.path.isfile() 过滤。

    import os files = [] for name in os.listdir("./模拟桌面"): if os.path.isfile(os.path.join("./模拟桌面", name)): files.append(name) # 只要文件，子文件夹不要 print("扫到", len(files), "个文件：") print(files)
    扫到 3 个文件： ['笔记.txt', '头像.png', '神秘文件.xyz']

    注意 isfile 判断时传的是完整路径（join 拼出来的），只传文件名的话，Python 不知道去哪个文件夹找它。另外输出顺序因系统而异——listdir 不保证顺序，做统计时别依赖它。

    STEP 3分类与移动 —— splitext 查户口，shutil.move 搬家

    文件叫 "头像.PNG"，扩展名是大写怎么办？先 .lower() 统一成小写再比对，规则就百发百中。拿扩展名用 os.path.splitext：它把 "头像.png" 拆成 ("头像", ".png")，取第 [1] 位。

    import os, shutil RULES = { "图片": [".jpg", ".png", ".gif"], "文档": [".pdf", ".txt", ".docx"], } def classify(filename, rules): ext = os.path.splitext(filename)[1].lower() # ".PNG" → ".png" for category, ext_list in rules.items(): # 键值对一起遍历 if ext in ext_list: return category # 命中：返回分类名 return None # 没规则匹配 → None print(classify("头像.PNG", RULES)) # 大小写也难不倒它 print(classify("神秘文件.xyz", RULES)) # 未知扩展名 → None src = os.path.join("./模拟桌面", "头像.png") dst = os.path.join("./模拟桌面", "图片", "头像.png") if os.path.exists(dst): # 目标已有同名文件！ print("[警告] 目标已有同名文件，改名再移！") else: shutil.move(src, dst) # 真正的搬家 print("[移动] 头像.png → 图片/")
    图片 None [移动] 头像.png → 图片/

    再运行一遍试试（文件已经在 图片/ 里了）：这次会走到警告分支——

    图片 None [警告] 目标已有同名文件，改名再移！

    ⚠️ 为什么移动前必须 exists 检查？因为 shutil.move 在目标已有同名文件时可能直接覆盖——两个"简历.pdf"只有一份能活下来。安全做法：同名就改名（加个"重命名_"前缀）再搬。完整代码里就是这么干的。

    STEP 4日志与规则文件 —— 追加模式 + json + 异常处理

    整理日志要用追加模式 "a" 打开：每次运行的结果接在文件末尾，历史记录一条不丢（用 "w" 会把上次的记录抹掉！）。规则也可以存成 json 文件，想改规则不用改代码——这就是配置与代码分离的思想。

    import json from datetime import datetime log_path = "./整理日志.txt" with open(log_path, "a", encoding="utf-8") as f: # "a" = 追加，不覆盖 f.write("===== " + datetime.now().strftime("%Y-%m-%d %H:%M:%S") + " 整理记录 =====\n") f.write("成功移动：9 个，跳过：2 个\n\n") try: with open("./规则.json", "r", encoding="utf-8") as f: rules = json.load(f) # json 文件 → 字典 print("规则读取成功：", rules) except FileNotFoundError: # 文件不存在？不崩，降级处理 print("[提示] 没有规则文件，等会儿用内置默认规则")
    [提示] 没有规则文件，等会儿用内置默认规则

    连跑两遍，打开 整理日志.txt 看看——两份记录都在，这就是追加模式的功劳：

    ===== 2026-08-23 21:57:35 整理记录 ===== 成功移动：9 个，跳过：2 个 ===== 2026-08-23 21:57:35 整理记录 ===== 成功移动：9 个，跳过：2 个

    想把规则导出成 json？一行 json.dump 搞定（ensure_ascii=False 让中文原样保存）：

    import json rules = {"图片": [".jpg", ".png", ".gif"], "文档": [".pdf", ".txt"]} with open("./规则.json", "w", encoding="utf-8") as f: json.dump(rules, f, ensure_ascii=False, indent=2)

    异常处理是这一步的主角：json 文件被手滑删了？格式写坏了？try/except 一接，程序不崩、降级到内置默认规则——这才配叫"自动化"。

    STEP 5统计与主流程 —— 字典计数，一环扣一环

    统计各分类移动了几个，最适合的还是字典：stats.get(分类, 0) + 1 一行搞定"有则加一、无则从零开始"。最后把所有环节串进 main() 主流程。

    stats = {} def count(stats, category): stats[category] = stats.get(category, 0) + 1 # 没有 key 就当 0 count(stats, "图片") count(stats, "图片") count(stats, "文档") print(stats) print("图片" in stats) # 成员检查 for category in sorted(stats): # 排序后遍历，输出稳定 print(category, "：", stats[category], "个")
    {'图片': 2, '文档': 1} True 图片 ： 2 个 文档 ： 1 个

    主流程的骨架长这样（完整版在下一步）：检查目标文件夹存在 → 读规则 → 建房 → 扫描 → 逐个分类移动（每个文件单独 try/except，一个失败不影响其他）→ 打印统计 → 写日志。用 if __name__ == "__main__": 收尾——被 import 时不自动运行，直接运行才执行。

    STEP 6合体！完整代码（约 105 行）与实测

    把前 5 步按规则合并，就是最终项目。完整代码如下（也可以从上往下逐块对照，确认你写的和它一致）：

    import os import shutil import json from datetime import datetime # ========== 配置区：想改规则只改这里 ========== DEFAULT_RULES = { "图片": [".jpg", ".jpeg", ".png", ".gif", ".bmp"], "文档": [".doc", ".docx", ".pdf", ".txt", ".md", ".pptx"], "表格": [".xls", ".xlsx", ".csv"], "安装包": [".exe", ".dmg", ".zip", ".rar", ".7z"], "视频": [".mp4", ".mov", ".avi", ".mkv"], } TARGET_DIR = "./模拟桌面" SAFE_MODE = True # 白名单模式：不在规则里的文件一律不动 def load_rules(path="./规则.json"): """优先从 json 配置文件读规则，读不到就用内置默认规则""" if os.path.exists(path): try: with open(path, "r", encoding="utf-8") as f: return json.load(f) except (json.JSONDecodeError, OSError) as e: print("[警告] 规则文件读取失败，使用内置规则：", e) return DEFAULT_RULES def scan_files(target_dir): """扫描目录，返回文件名列表（跳过子文件夹）""" files = [] for name in os.listdir(target_dir): if os.path.isfile(os.path.join(target_dir, name)): files.append(name) return files def classify(filename, rules): """根据扩展名返回分类名；没有匹配的规则返回 None""" ext = os.path.splitext(filename)[1].lower() for category, ext_list in rules.items(): if ext in ext_list: return category return None def make_rooms(target_dir, rules): """为每个分类创建子文件夹，已存在就跳过""" for category in rules: folder = os.path.join(target_dir, category) if not os.path.exists(folder): os.makedirs(folder) print("[建房] 创建分类文件夹：", category + "/") def move_file(target_dir, filename, category): """把文件移动进分类文件夹，成功返回 True""" src = os.path.join(target_dir, filename) dst = os.path.join(target_dir, category, filename) if os.path.exists(dst): # 目标已有同名文件：改名保平安 dst = os.path.join(target_dir, category, "重命名_" + filename) try: shutil.move(src, dst) return True except OSError as e: print("[失败]", filename, "移动出错：", e) return False def write_log(target_dir, moved, skipped, stats): """把本次整理结果追加写进日志文件""" log_path = os.path.join(target_dir, "整理日志.txt") time_str = datetime.now().strftime("%Y-%m-%d %H:%M:%S") with open(log_path, "a", encoding="utf-8") as f: f.write("===== " + time_str + " 整理记录 =====\n") f.write("成功移动：" + str(moved) + " 个，跳过：" + str(skipped) + " 个\n") for category in sorted(stats): f.write(" " + category + "：" + str(stats[category]) + " 个\n") f.write("\n") def main(): if not os.path.isdir(TARGET_DIR): print("[错误] 目标文件夹不存在：", TARGET_DIR) return rules = load_rules() print("[开始] 整理目标：", TARGET_DIR) make_rooms(TARGET_DIR, rules) stats = {} moved, skipped = 0, 0 for filename in scan_files(TARGET_DIR): if filename.startswith("整理日志"): # 别把日志自己整理走 continue category = classify(filename, rules) if category is None: skipped += 1 print("[跳过]", filename, "（没有匹配的分类规则）") continue if move_file(TARGET_DIR, filename, category): stats[category] = stats.get(category, 0) + 1 moved += 1 print("[移动]", filename, "→", category + "/") print("[统计] 共处理文件", moved + skipped, "个：移动", moved, "个，跳过", skipped, "个") for category in sorted(stats): print(" -", category, "：", stats[category], "个") write_log(TARGET_DIR, moved, skipped, stats) print("[完成] 日志已追加到", os.path.join(TARGET_DIR, "整理日志.txt")) if __name__ == "__main__": main()

    实测来了！往 模拟桌面 里丢 11 个文件（.jpg / .png / .pdf / .txt / .xlsx / .csv / .exe / .zip / .mp4 / .xyz / 无扩展名的 readme），运行第一遍——

    [开始] 整理目标： ./模拟桌面 [建房] 创建分类文件夹： 图片/ [建房] 创建分类文件夹： 文档/ [建房] 创建分类文件夹： 表格/ [建房] 创建分类文件夹： 安装包/ [建房] 创建分类文件夹： 视频/ [移动] 笔记.txt → 文档/ [移动] 头像.png → 图片/ [跳过] 神秘文件.xyz （没有匹配的分类规则） [移动] 旅行照片.jpg → 图片/ [移动] 课程表.xlsx → 表格/ [移动] 安装包.exe → 安装包/ [移动] 简历.pdf → 文档/ [移动] 电影.mp4 → 视频/ [移动] 游戏.zip → 安装包/ [跳过] readme （没有匹配的分类规则） [移动] 数据.csv → 表格/ [统计] 共处理文件 11 个：移动 9 个，跳过 2 个 - 图片 ： 2 个 - 安装包 ： 2 个 - 文档 ： 2 个 - 表格 ： 2 个 - 视频 ： 1 个 [完成] 日志已追加到 ./模拟桌面/整理日志.txt

    马上再运行第二遍——什么都没重复移动：文件已归位、房间已存在、日志被跳过，只剩两个不认识的文件继续被白名单保护：

    [开始] 整理目标： ./模拟桌面 [跳过] 神秘文件.xyz （没有匹配的分类规则） [跳过] readme （没有匹配的分类规则） [统计] 共处理文件 2 个：移动 0 个，跳过 2 个 [完成] 日志已追加到 ./模拟桌面/整理日志.txt

    第二遍零移动零报错，说明脚本是可重复运行的（行话叫"幂等"）——这是自动化脚本的基本修养。再看一眼 整理日志.txt，两份整理记录整整齐齐地追加在一起。BOSS，卒。🎉

    6🚀 进阶挑战 · 让 BOSS 刮目相看

    基础版通关只是及格线。下面三个进阶方向，任选其一都能让项目亮起来：

    挑战一 · 定时任务 schedule：手动运行算什么自动化？装好第三方库（终端执行 pip install schedule）后，几行代码让它自己定时跑——
    import schedule import time def job(): print("开始整理桌面……") # 这里调用你的 main() 即可（把上面的完整代码存成 整理器.py， # 然后 from 整理器 import main） schedule.every(10).minutes.do(job) # 每 10 分钟一次 schedule.every().day.at("09:00").do(job) # 每天早上 9 点 while True: schedule.run_pending() # 到点就触发任务 time.sleep(1) # 不然 CPU 会被跑满
    挑战二 · 按日期归档：文件多的时候，"图片/"里也会挤成一锅粥。给每个分类再套一层日期子文件夹（图片/2026-08-23/xxx.jpg），用 datetime 动态生成文件夹名——
    from datetime import datetime import os subfolder = datetime.now().strftime("%Y-%m-%d") # "2026-08-23" dst = os.path.join(target_dir, category, subfolder) os.makedirs(dst, exist_ok=True) # exist_ok=True：存在也不报错
    挑战三 · 白名单保护再升级 + watchdog：给绝对不能动的文件加"护盾"清单（比如 PROTECTED = {"重要配置.ini"}，扫描时跳过它们）；再进一步，装 pip install watchdog 监控文件夹——有新文件掉进来立刻自动归类，连定时都不用等。watchdog 涉及事件回调，正好是第 16 课「类与对象」之后才能完全看懂的东西，先混个眼熟。
