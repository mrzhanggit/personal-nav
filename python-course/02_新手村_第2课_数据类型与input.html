    今天要盯紧三个容易看走眼的细节：

    ① "18" 和 18 是两个种族：前者是文字（str），后者是整数（int）。长得一样，脾气完全不同。

    ② 10 和 10.0 也不同：int 和 float 是两个类型，虽然数值相等（10 == 10.0 是 True）。

    2炼金台：类型转换三咒语

    种族不同不能通婚——第 1 课 "等级：" + 10 的爆炸还历历在目。解决方法就是炼金术（类型转换）：把数据从一个种族变成另一个种族。

    print(int("20")) # 20 文字 → 整数 print(float("3.5")) # 3.5 文字 → 小数 print(str(42)) # 42 整数 → 文字（结果是不带引号显示的 "42"） print(int(9.9)) # 9 int() 砍掉小数部分，直接截断、不四舍五入！

    3炼金事故现场：ValueError

    炼金术不是万能的。int() 只认「纯整数文字」：字符串里混进小数点、字母、空格以外的任何东西，都会当场爆炸：

    print(int("3.5")) # 💥 爆炸！里面有小数点 print(int("abc")) # 💥 爆炸！abc 根本不是数字
    ValueError: invalid literal for int() with base 10: '3.5'

    两个安全姿势：

    # 姿势一：含小数点的文字，先 float 再 int print(int(float("3.5"))) # 3 # 姿势二：判断不了就先 float，绝不硬 int hp = float("99.5") # 99.5

    ⚠️ 未来的课会学到 try / except，可以优雅地「接住」这种爆炸。现在只需认识它：ValueError = 你给的数据，这个函数咽不下去。

    4input()：本课最大的陷阱

    input() 是程序和玩家对话的咒语：屏幕上弹出提示语，程序停下来等玩家打字，回车后把打的内容交给一个变量。

    name = input("你的名字：") age = input("你的年龄：") # 假设玩家输入 18 print("你好，", name)
    你好， 阿呆

    💎 核心真相（刻在脑门上）：input() 得到的永远是字符串，哪怕玩家输入的是数字。

    玩家输入 18，程序拿到的其实是文字 "18"。直接拿去做数学运算，就是本课经典事故：

    print(type(age)) # <class 'str'> —— 是文字！ print(age + 1) # 💥 TypeError: 文字不能加数字 print(int(age) + 1) # 19 ✅ 先转成整数再运算
    🧠 一招封印陷阱：要用玩家输入的数字做运算，永远先套一层 int() 或 float()。
    常见写法：age = int(input("你的年龄：")) —— 一行完成「输入 + 转换」。当然，如果玩家输入的不是数字，int() 会按上一节的方式抛 ValueError。

    5种族混血规则：隐式类型转换

    有些运算 Python 会自动帮你转换类型，不用念咒语，这叫「隐式转换」。规则只有两条，但没人教必踩坑：

    # 规则一：int 遇上 float，结果升级成 float print(1 + 2.5) # 3.5 print(3 + 4.0) # 7.0 只要有一方是 float，结果就是 float # 规则二：bool 参与算术运算，True 当 1，False 当 0 print(True + 5) # 6 print(False * 10) # 0 print(True + True) # 2
    📌 注意边界：自动转换只发生在数字家族内部（int / float / bool 互相之间）。
    str 和任何数字之间绝不会自动转换——"5" + 5 照样 TypeError，必须手动 str() 或 int()。
