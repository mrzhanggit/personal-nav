    • 1if：世界上最简单的岔路口

    前面的程序都是「一条道走到黑」——从第一行跑到最后一行。但游戏需要判断：血量低要不要报警？钱够不够买装备？这就要 if（如果）登场：

    hp = 30 if hp < 50: print("警告！血量过低，快撤退！") # 这行属于 if，条件成立才会执行 print("战斗继续...") # 这行顶格，永远会执行
    警告！血量过低，快撤退！ 战斗继续...

    岔路口示意图（把鼠标移上去感受两条路的命运）：

    hp < 50 成立（30 < 50 ✅） → 走进 if 块 → ⚠️ 打印「警告！血量过低」
    hp < 50 不成立 → 跳过整个 if 块 → 直接去执行顶格的下一行
    🧠 if 结构三要素：① if 后面跟条件 ② 条件后面必须有英文冒号 : ③ 下一行缩进 4 个空格，缩进的行才是 if 的「地盘」。

    2elif 链与 else 兜底：多岔路口

    只有两条路不够用？elif（否则如果）可以接出一连串岔路，else（否则）负责兜底——所有条件都不成立时走它：

    score = 75 if score >= 90: print("S 级 · 传说") elif score >= 75: print("A 级 · 优秀") # ← 75 命中这条 elif score >= 60: print("B 级 · 及格") else: print("C 级 · 勇者加油")
    A 级 · 优秀

    走法铁律：从上往下逐个检查，命中第一条就走它，走完立刻离开整个岔路口——后面的分支看都不看一眼。所以 75 命中 score >= 75 后，就算它也满足 score >= 60，也轮不到那条了。

    else 永远放最后、不带条件、直接冒号，是「以上全不中」的保底出口，最多只能有一个。

    3缩进即语法：Python 的地盘规则

    这是 Python 和 JavaScript 最大的区别。JS 用花括号 { } 圈地盘，缩进只是好看；Python 直接用缩进当地盘边界，缩进错了 = 语法错了：

    # JavaScript 世界：花括号说了算，缩进只是化妆 if (hp < 50) { print("警告"); } # Python 世界：缩进说了算，没有花括号 if hp < 50: print("警告") # 缩进了 → 属于 if

    忘了缩进，Python 当场翻脸：

    level = 5 if level > 3: print("解锁进阶区") # 💥 IndentationError！print 忘了缩进
    IndentationError: expected an indented block
    📐 缩进三规矩：① 同一个代码块必须对齐（都缩 4 个空格，这是官方惯例）；② 同一块里时缩时不错（忽 4 格忽 2 格 → IndentationError）；③ 别混用 Tab 和空格，编辑器里统一设置成「Tab 键 = 4 空格」一劳永逸。

    4比较运算符：六把命运之尺

    if 后面的条件，大多由比较运算符构成。比较的结果是布尔值——非 True 即 False：

    == 等于
    5 == 5 → True
    != 不等于
    5 != 3 → True
    > 大于
    3 > 10 → False
    < 小于
    3 < 10 → True
    >= 大于等于
    5 >= 5 → True
    <= 小于等于
    4 <= 3 → False

    顺便复习上一课："18" == 18 是 False——一个是文字一个是数字，种族不同不相等。

    5逻辑运算符：and / or / not

    多个条件怎么组合？三个逻辑运算符登场：

    if hp > 0 and mp > 10: # and：两边都成立才算成立 print("技能就绪") if hp < 30 or mp < 5: # or：任意一边成立就成立 print("状态危险") if not is_dead: # not：把真假反过来 print("还能抢救")

    动手玩一下逻辑门——点击 A、B 切换真假，右边实时显示 Python 的判定结果：

    ⚡ 逻辑门实验室
    A =
    B =
    print(A and B) → False　（两边都 True 才 True）
    print(A or B) → True　（有一边 True 就 True）
    print(not A) → False　（把 A 反过来）

    两条进阶规则（先混个脸熟）：

    ① 优先级：not > and > or。拿不准就加括号，括号永远最优先：

    print(True or False and False) # True —— 先算 False and False = False，再 True or False = True

    ② 短路：and 左边是 False 就直接得 False，右边看都不看；or 左边是 True 就直接得 True：

    hp = 0 if hp > 0 and 10 / hp > 2: # hp > 0 是 False → 短路！10/hp 根本不会执行 print("安全") # 输出：什么都没有（但也不会报除零错误，这就是短路的保护）

    6== 与 = ：一个符号的天壤之别

    新手报错排行榜常年前三名：把 == 写成 =。一个等号是「赋值」——把东西塞进盒子；两个等号才是「比较」——问一句「相等吗」：

    x = 10 if x = 20: # 💥 SyntaxError！if 需要的是条件，不是赋值动作 print("相等") if x == 20: # ✅ 这才是「x 等于 20 吗？」——答案是 False，什么都不打印 print("相等")
    🧠 念咒防坑：写条件时把 == 念成「等于吗？」，把 = 念成「装进去」。嘴巴一念，手就不会滑。

    7嵌套 if：门里还有门

    if 里面还可以再放 if——像洋葱一样层层剥开，每层都有自己的缩进：

    hp = 80 mp = 10 if hp > 50: # 外层大门：血量够吗？80 > 50 ✅ 进 if mp > 50: # 内层小门：蓝量够吗？10 > 50 ❌ 不进 print("大招释放！") else: # 走内层的 else print("蓝量不足，普攻") else: print("血量危险，先保命")
    蓝量不足，普攻

    读嵌套代码的诀窍：从外往里一层层问。外层不成立，里面整层直接跳过。注意内层 if 整体比外层又缩进了一级（4 格变 8 格）——缩进层级就是嵌套深度。
