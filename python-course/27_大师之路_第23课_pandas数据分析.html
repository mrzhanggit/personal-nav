    • 1千里眼的两件法宝：DataFrame 与 Series

    前 22 课你的数据都是一个个零散的变量。真实世界的数据是一整张表：几百行学生成绩、几万条销售记录。pandas 的 DataFrame 就是带标签的二维表格——每列有列名，每行有行号（索引）。

    📐 DataFrame

    整张表：行索引 + 列名
    像一张会计算的 Excel

    → 抽出一列 →
    📏 Series

    带标签的一维序列
    DataFrame 的每一列就是一个 Series

    手工造一张小表感受一下（把鼠标移到上面的卡片上）：

    import pandas as pd df = pd.DataFrame({ "姓名": ["阿呆", "小满", "铁柱"], "科目": ["数学", "语文", "英语"], "分数": [92, 85, 78], }) print(df)
    姓名 科目 分数 0 阿呆 数学 92 1 小满 语文 85 2 铁柱 英语 78

    最左边一列 0 1 2 就是行索引（自动生成），第一行是列名。DataFrame 的每一列，单独拿出来就是一个 Series。

    🧠 记忆口诀：DataFrame 是一张表，Series 是表里的一列。

    2读数据 + 三板斧：先看一眼再动手

    真实数据通常存在 CSV 文件里（逗号分隔的表格文本）。一行代码读进来：

    import pandas as pd df = pd.read_csv("scores.csv") # 读入 CSV，得到 DataFrame（15 名学生的成绩表）

    拿到陌生数据，先抡三板斧，从粗到细看清全貌：

    3选列与条件筛选：千里眼的透视眼

    选一列：用中括号 + 列名（字符串），返回 Series：

    scores = df["分数"] # 一列 → Series print(type(df["分数"]))
    <class 'pandas.core.series.Series'>

    条件筛选：方括号里放一个「布尔条件」，pandas 只留下条件为 True 的行——这是数据分析最高频的操作：

    df[df["分数"] > 90] # 筛出分数大于 90 的所有行
    姓名 科目 分数 学习时长 0 阿呆 数学 92 5.0 3 灵儿 数学 95 6.0 7 月月 语文 91 6.5 10 阿宝 语文 97 7.0

    注意行索引还是 0 3 7 10——筛选不重排行号，只是抽出了符合条件的行。

    多条件：用 &（且）和 |（或）连接，每个条件必须用括号包住：

    df[(df["分数"] > 90) & (df["科目"] == "数学")] # 分数>90 且 是数学
    姓名 科目 分数 学习时长 0 阿呆 数学 92 5.0 3 灵儿 数学 95 6.0

    ⚠️ 经典大坑：不能写成 and / or！Python 的 and 试图对整个 Series 求真假，pandas 会直接拒绝：

    df[(df["分数"] > 90) and (df["科目"] == "数学")] # 💥 报错！ # ValueError: The truth value of a Series is ambiguous

    🧠 记忆口诀：pandas 里「且 & 或 |」，括号一个不能少。

    4排序与分组聚合：排出英雄榜

    排序：sort_values 按某一列排，ascending=False 表示从高到低（默认从低到高）：

    df.sort_values("分数", ascending=False).head(3) # 分数前三名
    姓名 科目 分数 学习时长 10 阿宝 语文 97 7.0 3 灵儿 数学 95 6.0 0 阿呆 数学 92 5.0

    分组聚合：分组聚合是数据分析的灵魂操作——groupby 先按某列分组，再对每组算一个统计量。「每个科目的平均分是多少？」一句话搞定：

    df.groupby("科目")["分数"].mean() # 按科目分组，对分数求平均
    科目 数学 85.0 英语 76.8 语文 83.0 Name: 分数, dtype: float64

    结果从 15 行变成 每组一行——这正是「分组」的含义。把 mean 换成 sum、max、min 同理；想一次算多个指标就用 agg：

    df.groupby("科目")["分数"].agg(["mean", "max"]) # 每科的平均分 + 最高分
    mean max 科目 数学 85.0 95 英语 76.8 89 语文 83.0 97

    🧠 记忆口诀：groupby 分家，聚合算总账。

    5新增列 · 统计分布 · 保存结果

    新增计算列：像给普通变量赋值一样，直接给一个新列名赋值——整列会逐行自动计算：

    df["效率"] = (df["分数"] / df["学习时长"]).round(1) # 每小时得几分 df.head(3)
    姓名 科目 分数 学习时长 效率 0 阿呆 数学 92 5.0 18.4 1 小满 语文 85 4.5 18.9 2 铁柱 英语 78 3.0 26.0

    铁柱效率 26.0 全班第一——分数不是唯一的标准，这就是「新增列」的价值：派生出新的观察角度。

    统计分布：value_counts() 数一数每类出现了几次（调查问卷、分类统计神器）：

    df["科目"].value_counts()
    科目 数学 5 语文 5 英语 5 Name: count, dtype: int64

    保存结果：分析完的表一行存回 CSV，index=False 表示不把行号写进文件：

    df.to_csv("result.csv", index=False) # 保存为 result.csv，可用 Excel 打开

    至于画图：pandas 和 matplotlib 是黄金搭档，一行就能出柱状图（如 df["科目"].value_counts().plot(kind="bar")），以后再专门修炼，今天先会算就行。
