    • 1while：无限回廊的开启条件

    想象一座回廊：门口有一个守卫，每次你想再绕一圈，他都会检查一次「通行条件」。条件为 True，放行继续绕；条件为 False，把你扔出出口。这就是 while 循环。

    ⛩ ⛩ ⛩ ⛩ ⛩ ⛩ ⛩ ⛩ ⛩ ⛩ ⛩ ⛩ ⛩ ⛩ ⛩ ⛩
    🚶
    条件 hp > 0 一直为真：英雄在回廊里一圈又一圈……直到 hp 归零，出口才打开
    hp = 5 while hp > 0: # 守卫检查条件：hp 大于 0 就继续绕 print("战斗中，剩余 HP：", hp) hp -= 1 # 每绕一圈扣 1 点，条件迟早会变 False print("回廊出口已开启") # 循环结束后才执行这一行
    战斗中，剩余 HP： 5 战斗中，剩余 HP： 4 战斗中，剩余 HP： 3 战斗中，剩余 HP： 2 战斗中，剩余 HP： 1 回廊出口已开启
    ⚠️ 死循环警告：如果忘了写 hp -= 1，条件永远为 True，程序将无限刷屏停不下来——这就是死循环。在终端里按 Ctrl + C 可以强制停止它。写 while 时永远先问自己：什么东西在让条件走向 False？

    2for + range()：计数型回廊

    如果你只是想「精确绕 3 圈」，用 while 得自己维护计数器，太麻烦。Python 给你一台传送带：range() 负责按顺序吐出数字，for 负责每个都接住处理一遍。

    for i in range(3): print("第", i, "圈")
    第 0 圈 第 1 圈 第 2 圈

    range(3) 只送出 0、1、2 三个数字——从 0 开始、共 3 个、不含 3。记住这个规则，能帮你避开新手村一半的 bug：

    range(101) # 0, 1, 2, ... 100（从 0 开始，共 101 个） range(1, 101) # 1, 2, 3, ... 100 —— 从 1 数到 100，不含 101！ range(1, 10, 2) # 1, 3, 5, 7, 9 —— 第三个参数是步长，每次跳 2
    🧭 最重要的边界：想「从 1 数到 100」，要写 range(1, 101) 而不是 range(1, 100)。range 是左闭右开区间：包含左端，不含右端。

    3break 与 continue：暗门与跳过格

    回廊里有两个特殊机关：break 是一扇暗门——踩到立刻离开整条回廊；continue 是一块跳过格——跳过这一格的剩余机关，直接去下一格。

    1
    2
    3
    4break 🚪
    5没机会了
    for i in range(1, 6): if i == 4: break # 破门而出：整个循环立刻结束 print(i)
    1 2 3

    把 break 换成 continue，结果完全不同：

    for i in range(1, 6): if i == 4: continue # 只跳过 4 这一格，继续 5 print(i)
    1 2 3 5

    🧠 记忆口诀：break 是「我不玩了」，continue 是「这个不要，下一个」。

    4for 遍历字符串：逐字扫描

    for 不只能配 range，还能直接把字符串当成传送带：每次送出一个字符。

    skill = "冰霜箭" for ch in skill: # ch 依次是 '冰'、'霜'、'箭' print("飞出符文：", ch)
    飞出符文： 冰 飞出符文： 霜 飞出符文： 箭

    这个技巧以后天天用：比如数一句话里有多少个字、把名字逐个字母加密。字符串有几个字符，循环就转几圈。

    5累加器模式：循环 + 存钱罐

    「循环 + 一个不断累积的变量」是编程世界出镜率最高的模式。就像存钱罐：出发前先清空（total = 0），每绕一圈存一点（total += x）。

    +1 后
    1
    +2 后
    3
    +3 后
    6
    total = 0 # 出发前清空存钱罐 for x in range(1, 101): # 1, 2, 3, ... 100（不含 101） total += x # 等价于 total = total + x print("1 加到 100 =", total)
    1 加到 100 = 5050

    传说高斯手算的题，你的程序 100 圈循环秒解。把 += 换成 *= 就是累乘（算阶乘），把 total = 0 换成 total = 1 即可——模式不变，只换运算。

    6嵌套循环：回廊里套回廊

    循环体里还能再放一个循环——外层每绕一圈，内层就完整跑一遍。经典实战：九九乘法表。外层 i 控制第几行，内层 j 打印行里的每个算式。

    for i in range(1, 10): # i：第 1~9 行 for j in range(1, i + 1): # j：每行打印 i 个算式 print(j, "x", i, "=", i * j, end="\t") print() # 一行打完，换行（end="\t" 让算式留在同一行）
    1 x 1 = 1 1 x 2 = 2 2 x 2 = 4 1 x 3 = 3 2 x 3 = 6 3 x 3 = 9 ……（每行比上一行多一个算式，一直到第 9 行）

    算一笔账：内层总共执行 1+2+3+…+9 = 45 次。嵌套循环的总执行次数 = 外层次数 × 内层次数，数据一大就会变慢，心里要有这本账。
