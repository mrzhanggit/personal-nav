    • 1继承：class 子类(父类)

    RPG 里法师、战士、盗贼各有绝活，但他们都会走路、都有名字和血量——这些公共能力没必要写三遍。把它们抽到一个父类 Hero，三个职业类再用一行语法「认祖归宗」：

    class Hero: def __init__(self, name): self.name = name def attack(self): return self.name + " 发动普通攻击" class Mage(Hero): # 括号里写父类名 = 继承 pass # 什么都不写也行 m = Mage("梅林") print(m.name) # name 是父类 __init__ 建的，直接能用 print(m.attack()) # 父类的方法也能直接调用
    梅林 梅林 发动普通攻击

    记住这句话：子类自动获得父类的全部属性和方法，一行都不用重写。这就是"血脉传承"——你继承了英雄家族的血统，天生就会挥拳。

    父类 Hero
    name · hp · attack()
    Warrior 战士
    继承全部 + 新增怒气
    Mage 法师
    继承全部 + 新增魔力
    Rogue 盗贼
    继承全部 + 新增敏捷

    2方法重写与 super().__init__()

    继承来的攻击是"挥拳"，战士表示不服：我要用巨剑！解决办法是方法重写（override）——子类里定义一个和父类同名的方法，调用时子类版本会覆盖父类版本：

    父类 Hero 的 attack（被覆盖）
    def attack(self): return "挥拳攻击，5 点伤害"
    已被覆盖
    ⚡ 子类 Warrior 重写的 attack（生效）
    def attack(self): return "挥舞巨剑，20 点伤害"

    那如果子类想既保留父类的初始化，又加点自己的新属性呢？用 super().__init__()——super 意思是"父类"，这行咒文表示「先请父类的 __init__ 干完它的活，我再接着干」：

    class Hero: def __init__(self, name, hp): self.name = name self.hp = hp def attack(self): return self.name + " 挥拳攻击" class Warrior(Hero): def __init__(self, name, hp, rage): # 新增怒气参数 super().__init__(name, hp) # 第一步：父类负责 name 和 hp self.rage = rage # 第二步：自己再添新属性 def attack(self): # 重写：覆盖父类攻击 return self.name + " 挥舞巨剑" w = Warrior("铁柱", 100, 50) print(w.attack()) print(w.hp, w.rage) # 父类的、自己的属性全都有
    铁柱 挥舞巨剑 100 50

    🧠 记忆口诀：super 打头阵，新属性随后。惯例是把 super().__init__() 写在子类 __init__ 的第一行——先继承家业，再添新产业。

    ⚠️ 头号大坑：子类一旦写了 __init__ 却忘记调用 super().__init__()，父类那套属性就根本不会被创建，访问 w.name 直接 AttributeError 爆炸（预言机第 1 题就考这个）。

    3isinstance 验血统 · 多态初体验

    isinstance(对象, 类) 用来判断对象是不是某个类的实例。关键规则：子类实例同时也是父类的实例——法师当然也是英雄：

    class Hero: def attack(self): return "普通攻击" class Warrior(Hero): def attack(self): return "重斩！" class Mage(Hero): def attack(self): return "火球术！" heroes = [Warrior(), Mage()] for h in heroes: print(h.attack()) # 同一句代码，各显神通 print(isinstance(heroes[0], Hero)) # 战士也是英雄 → True print(isinstance(heroes[0], Mage)) # 但战士不是法师 → False
    重斩！ 火球术！ True False

    上面最妙的是那段 for 循环：同一个 h.attack() 调用，战士出重斩、法师放火球——这就是多态（polymorphism）：同一个方法名，不同子类各自实现、各显神通。写代码时不用关心对象具体是什么职业，调用就完事。

    Warrior()attack() → 重斩！
    Mage()attack() → 火球术！
    isinstance(x, Hero)两个都验血通过 → True

    4魔法方法：双下划线的隐藏咒文

    print 一个对象时显示 <__main__.Pet object at 0x1024...> 这种天书？两个对象用 == 比较总是不相等？那是因为你还没念对咒文。魔法方法是 Python 预留的机关：前后各两条下划线的名字（如 __str__），在你执行 print、==、+、len() 时被自动触发。

    __str__print(对象) 时的门面
    __repr__调试形态 / 容器里的样子
    __eq__定义 == 怎么比
    __len__让 len() 认识你
    __add__让对象支持 +

    ① __str__——print 的门面担当：

    class Pet: def __init__(self, name): self.name = name def __str__(self): return "宠物<" + self.name + ">" p = Pet("旺财") print(p) # print 会自动调用 __str__
    宠物<旺财>

    ② __repr__——程序员看的"出厂标签"，放在列表等容器里时用它显示：

    class Point: def __init__(self, x, y): self.x = x self.y = y def __repr__(self): return "Point(" + str(self.x) + ", " + str(self.y) + ")" p = Point(3, 4) print([p]) # 容器里的元素用 __repr__ 显示 print(repr(p)) # 主动调用 repr() 也是它
    [Point(3, 4)] Point(3, 4)

    ③ __eq__——自定义"相等"的标准（默认 == 比的是"是不是同一个对象"）：

    class Coin: def __init__(self, value): self.value = value def __eq__(self, other): return self.value == other.value print(Coin(10) == Coin(10)) # 面值相同就算相等 print(Coin(10) == Coin(50))
    True False

    ④ __len__——让 len() 读懂你的队伍有多少人：

    class Team: def __init__(self, members): self.members = members def __len__(self): return len(self.members) t = Team(["阿呆", "铁柱", "梅林"]) print(len(t))
    3

    ⑤ __add__——让对象之间也能用 + 合成：

    class Gem: def __init__(self, value): self.value = value def __add__(self, other): return Gem(self.value + other.value) def __repr__(self): return "Gem(" + str(self.value) + ")" combo = Gem(30) + Gem(70) # + 号触发 __add__ print(combo)
    Gem(100)

    🧠 一句话总结：运算符和内置函数只是表象，魔法方法才是背后的机关。
