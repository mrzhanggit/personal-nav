    • 1模块：现成的装备箱

    打副本最忌讳裸装上阵。你想要随机数？有人写好了。你想算平方根？有人写好了。这些写好的代码被打包成一个个「模块」，随时召唤。

    一个模块，你可以理解为：一个装满现成函数和变量的装备箱。想用里面的东西，只需要念一句咒语——import。

    math
    数学工具箱
    平方根 · 取整 · π
    random
    命运骰子
    随机数 · 随机抽取
    json
    存档转换器
    字典 ⇄ 文字互转

    把鼠标移到装备箱上看看。召唤它只要一行：

    import math # 召唤 math 装备箱 print(math.sqrt(144)) # 用箱子里名叫 sqrt 的工具算平方根
    12.0

    其实你早就见过模块了：print()、len() 是 Python 开机自带的内置函数，不用 import；而 sqrt、randint 藏在模块里，必须先 import 才能用——不召唤就伸手拿，会直接报 NameError。

    2召唤的两种姿势：import 与 from...import

    方式一：import xxx——整箱搬进屋，用的时候喊全名「箱名.工具名」。

    方式二：from xxx import yyy——只把一件工具拿出来，直接用名字。

    import math # 方式一：整箱搬进来 print(math.sqrt(9)) # 必须喊全名 math.sqrt from math import sqrt # 方式二：只拿 sqrt 这一件 print(sqrt(9)) # 直接喊 sqrt
    3.0 3.0

    两种姿势效果一样，怎么选？小口诀：用得多就整箱搬（import math），只用一两件就单拿（from math import sqrt）。

    ⚠️ 还有一种危险写法 from math import *——把整箱东西全部倒在地上不署名。工具一多就容易「撞名」：两个箱子都有 sqrt，后到的会覆盖先到的。新手阶段不推荐。

    3as：给外援起个短名

    有些模块名字太长（比如 pandas），喊起来费劲。用 as 给它起个代号：

    import random as rd # 从此 random 叫 rd rd.seed(42) print(rd.randint(1, 6)) # rd.randint，而不是 random.randint from datetime import date as d # from-import 的工具也能起别名 print(d(2025, 10, 1).isoformat())
    6 2025-10-01

    一个彩蛋惯例：import pandas as pd、import numpy as np 是全世界的程序员约好的代号，跟着写就对了。注意：起了别名之后只能用别名，再喊原名 random 反而会报错。

    4标准库百宝箱：自带七件神装

    Python 安装好就自带一大批模块，统称标准库——不用安装、不用下载，import 就能用。先认识七件最常用的：

    📦 math —— 数学工具箱
    import math print(math.sqrt(144)) # 平方根 print(math.floor(3.9)) # 向下取整 print(math.ceil(2.1)) # 向上取整
    12.0 3 3
    🎲 random —— 命运骰子
    import random random.seed(42) # 固定骰子，让输出可复现（实战可省略） print(random.randint(1, 6)) # 掷一个 1~6 的骰子（两头都能掷到） print(random.choice(["剑", "盾", "弓"])) # 从列表里随机抽一件
    6 剑
    ⏰ time —— 时间控制器
    import time print("蓄力中...") time.sleep(1) # 暂停 1 秒（回血动画全靠它） print("攻击！")
    蓄力中... 攻击！
    ※ 两行输出之间真实暂停了约 1 秒。
    📅 datetime —— 日历师
    from datetime import date print(date(2025, 10, 1).isoformat()) # 造一个日期并转成标准文字 print(date(2026, 1, 1) - date(2025, 1, 1)) # 日期相减 = 距离开服多少天
    2025-10-01 365 days, 0:00:00
    🗂️ os —— 和操作系统打交道
    import os print(os.path.join("bag", "sword.txt")) # 拼出一个跨系统的路径 print(os.getcwd()) # 当前在哪个文件夹
    bag/sword.txt /Users/hero/adventure
    ※ 第二行每台电脑都不同（此处为示例）；Windows 下第一行会输出 bag\sword.txt。
    💾 json —— 存档转换器
    import json hero = {"名字": "阿呆", "等级": 10} s = json.dumps(hero, ensure_ascii=False) # 字典 → JSON 文字（可写进文件） print(s) print(json.loads(s)["等级"]) # JSON 文字 → 字典
    {"名字": "阿呆", "等级": 10} 10
    🖥️ sys —— 系统信息台
    import sys print(sys.version_info[0]) # Python 大版本号 print(sys.argv) # 命令行参数列表
    3 ['hero.py', '阿呆']
    ※ 第二行为示例：在终端输入 python hero.py 阿呆 时，argv 就是脚本名加你传的参数。

    5pip：给装备库进货

    标准库之外，全世界的程序员还发布了上百万件更强的装备（第三方库）：画图表的 pandas、发网络请求的 requests、做网站的 Django……它们要用 pip 安装。

    ⚠️ pip 命令是在终端（命令行）里输入的，不是在 Python 里：

    # —— 终端命令，不是 Python 代码 —— pip install requests # 进货：安装第三方库 requests pip list # 盘点：列出已安装的所有库和版本号 pip uninstall requests # 退货：卸载（会问 y/n 确认）

    装好之后，用法和标准库一模一样：

    import requests # 曾经 pip install 过，现在直接召唤

    常见报错自查：终端里报 'pip' 不是内部或外部命令 → Python 没装好或没加入 PATH，重装时勾选 "Add Python to PATH"；在 Python 交互模式里输入 pip 命令 → pip 是终端命令，先输入 exit() 退出 Python 再敲。

    6虚拟环境 venv：每人一个独立背包

    副本打到后期会遇到一个棘手问题——版本冲突：

    项目 A
    需要库 1.0
    旧项目，锁定老版本
    项目 B
    需要库 2.0
    新项目，必须新版本

    如果所有库都装在同一个「全局背包」里，1.0 和 2.0 只能活一个，两个项目必然有一个崩。虚拟环境（venv）就是给每个项目发一个独立背包：各自的库、各自的版本、互不打架。

    # —— 终端命令，不是 Python 代码 —— python -m venv myenv # 在当前文件夹创建名为 myenv 的独立背包 # 进入背包（激活）： source myenv/bin/activate # macOS / Linux myenv\Scripts\activate # Windows pip install pandas # 现在只装进这个背包，不影响别人 deactivate # 离开背包

    判断自己是否在背包里的标志：终端提示符前面多了个 (myenv)。新手阶段可以先不建虚拟环境，但从今天起你要知道这个概念——它迟早会救你一命。

    7if __name__ == "__main__"：模块的双重身份

    每个 .py 文件都有一个隐藏变量 __name__，它的值由「你怎么运行」决定：

    • 直接运行（终端敲 python hero.py）→ __name__ 等于 "__main__"
    • 被别人导入（别的文件里 import hero）→ __name__ 等于 "hero"（模块名）

    所以 if __name__ == "__main__": 的意思是：「这段代码只在直接运行我时执行，被导入时别乱动」。

    # 文件 hero.py def attack(): print("挥剑！") if __name__ == "__main__": attack() # 只有直接运行 hero.py 时才会自动挥剑
    场景 A · 直接运行
    $ python hero.py
    __name__ == "__main__" → 条件成立
    ✅ 自动执行 attack()，屏幕输出「挥剑！」
    场景 B · 被导入
    main.py 里写：import hero
    __name__ == "hero" → 条件不成立
    ❌ 什么也不输出，attack 只是被「借走」备用
    # 文件 main.py import hero # 导入时静悄悄，不会输出「挥剑！」 hero.attack() # 需要的时候手动调用
    挥剑！

    为什么要这么设计？想象你写了满满一箱好用的函数，别的文件都想 import 来用——如果一被导入就自动跑测试代码，别人会疯掉。这行 if 就是把「给别人用的」和「自己测试用的」分开，是 Python 世界的礼貌 conventions（惯例）。
